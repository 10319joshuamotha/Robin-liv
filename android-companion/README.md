# Robin Android Companion

Native Android foundation for Robin's hybrid assistant.

- Windows executes Windows-local tasks.
- Android executes phone-local tasks such as alarms, notifications and calls.
- Direct LAN transport is preferred when devices are nearby.
- An authenticated cloud relay is used when devices are on different networks.
- Tasks already scheduled on Android remain local and do not depend on Windows staying online.

This is the initial Android project foundation. Pairing, cloud relay, secure device identity,
voice interaction, task routing, and production Android background execution are next.
