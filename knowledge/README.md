# Robin knowledge layer

Robin's science/engineering knowledge is organized by domain instead of being
stuffed into one giant system prompt.

Domains:
- mechanics
- chemistry
- physics
- electrical engineering
- electronics
- AutoCAD/CAD

The action registry exposes safe numerical calculations and AutoCAD command
guidance. For factual or current technical details, Robin should use web search
and cite authoritative sources.

Reference material should be openly licensed or otherwise permission-cleared.
OpenStax provides openly licensed science textbooks; licensing varies by title,
so Robin should follow the individual work's stated license and attribution
terms rather than copying entire books into model context.
